## ระบบจัดการภาษีมูลค่าเพิ่ม และค่าธรรมเนียมในระบบ ##
ระบบนี้เป็นระบบจัดการภาษีมูลค่าเพิ่ม และค่าธรรมเนียมในระบบ โดยมีฟังก์ชันหลักได้แก่ การแจกแจงภาษีมูลค่าเพิ่มออกจากสินค้า (กรณีที่ราคาสินค้ารวมภาษีแล้ว) และการบวกเพิ่มภาษีลงในราคาสินค้า (กรณีที่ราคาสินค้ายังไม่รวมภาษี)

<img width="1498" height="819" alt="image" src="https://github.com/user-attachments/assets/4453537e-7f3c-45f4-850d-f0346cab30fe" />

### เพิ่มเติม ###
ระบบสามารถบวกค่าธรรมเนียมการชำระด้วยบัตรเครดิต และออกใบเสร็จเฉพาะค่าธรรมเนียมนั้น ๆ ได้ เพื่อให้สามารถนำไปประกอบการทำบัญชี กรณีที่ผู้ซื้อเป็นบริษัทเอกชนหรือองค์กรของรัฐบาล

## การติดตั้ง ##
สามารถติดตั้งปลั้กอินนี้ได้โดยการดาวน์โหลดไฟล์นี้จาก Github หน้านี้ และอัพโหลดลงในหน้า /wp-admin/plugin-install.php หลังจากอัพโหลด และเปิดใช้งาน (Activate) ระบบจะทำการสร้างตารางและคอลัมน์ใหม่โดยอัตโนมัติ
